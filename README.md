# Student Admission Management System

A simple C# console application developed using Object-Oriented Programming (OOP) concepts.

## Features

- Add student details
- Display student information
- Uses Class and Object
- Uses Constructor
- Uses Access Modifiers

## Technologies Used

- C#
- .NET Console Application

│── Program.cs
